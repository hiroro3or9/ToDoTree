# ToDoTree

ゴールまでの道のりを **分岐と合流のあるグラフ（DAG）** で書き出して進める、C# / WPF の Todo 管理アプリ。

マインドマップのように枝を伸ばし、Git のブランチのように分かれた作業を合流させられます。
「いま着手できるステップ」はグラフから自動で判定されるので、次に何をやればいいか迷いません。

[ドキュメント一覧](docs/README.md) · [保存と復旧](docs/STORAGE.md) · [開発・検証](docs/DEVELOPMENT.md) · [ロードマップ](docs/ROADMAP.md)

## 主な機能

- **依存関係から次の行動を判断** … 着手可能なステップ、最長経路、期限から逆算した要着手日を自動で計算
- **素早く書き出して繋ぐ** … 箇条書きの一括入力、カード上での直接編集、分岐・合流、ステップの分割
- **大きなグラフを見渡す** … 自動整列、折りたたみ、フォーカスモード、タグ絞り込み、ミニマップ、丸と線だけのミニマル表示
- **一帯をまとめて動かす** … 複数のステップを名前付きのブロックで囲み、見出しをつかんで丸ごと移動
- **回数を決めて終わらせる** … 「練習を3回」を1枚のカードで管理し、最後の1回で完了して後続を解放
- **進捗を先まで読む** … 理由付きの「次にやること」、完了見込み、期限に間に合うかの判定
- **複数プロジェクトを並行して開く** … プロジェクトごとのタブ、独立したUndo・検索・表示状態、前回のタブ復元
- **外へ共有する** … Markdown / Mermaid への書き出しと、Mermaid 図のコピー
- **安心して保存する** … 読みやすい JSON 形式、原子的保存、バックアップ、自動保存、未保存データの復元

### 受信箱・チェックリスト・作業のブロック

- 左側の **受信箱（仮置き）** に名前を入力し、Enterまたは追加ボタンで登録できます。プロジェクトごとに保存され、配置するまでは進捗・計画・着手候補に含みません。
- 受信箱の名前をキャンバスへドラッグするか **配置** を押すとカードになります。配置後に接続点から前後の作業へ繋げられます。**×** で受信箱から削除できます。
- カードを選び、右の **チェックリスト** で項目を追加・編集・チェック・削除できます。カードにもチェック済み件数を表示します。全項目をチェックしてもカード自体は自動完了しません。
- 右の **作業をブロックする**、またはカードの右クリックから、いったん実施できない状態にできます。理由は任意です。ブロック中は「次にやること」から外れ、解除すると元の未着手・進行中状態に戻ります。
- **この作業・ゴールが止まっている理由** に、上流の手動ブロックと未完了の前提を表示します。原因をクリックすると、折りたたみや絞り込みを解除して該当カードへ移動します。完了・取り消し済みの前提より先は原因として数えません。
- ブロックは作業できない状況を記録する印です。実績の訂正や明示的な完了操作は引き続き可能で、完了・取り消しでブロックの印が外れます。理由のメモは残ります。
- 各操作はUndo/Redo、自動保存、未保存タブの復旧に対応します。部品からの配置ではチェック項目名を引き継ぎ、チェック済み状態と手動ブロックをリセットします。
- 保存形式は **9** です。旧形式は読み込めますが、この版で保存したファイルは旧アプリでは開けません。

### 作業のしおり

カードを選び、右側の **作業のしおり → 選択したカードにしおりを置く** を押すと、
再開する場所をプロジェクトにつき1つ保存できます。カード／ミニマル表示の両方に旗が付きます。
再開メモに「次にすること」「詰まったこと」を入力すると、通常の保存・自動保存・復旧の対象になります。

- **しおりへ戻る** で対象カードを画面中央に表示します。折りたたみ・フォーカス・完了非表示・検索・タグ絞り込みは解除され、前後のステップも確認できます。
- 保存したプロジェクトを開いたとき／次回起動時のタブ復元では、しおりの場所から表示します。開いた後のタブ切り替えでは通常どおり現在の表示位置を保持します。
- 別のカードへ置くと、以前のしおりと再開メモを置き換えます。**しおりを外す** で解除できます。
- 設置・置き換え・メモ編集・解除はUndoに対応します。対象カードを削除するとしおりも外れ、削除をUndoするとメモごと戻ります。カードを完了してもしおりは残ります。
- しおりは保存形式3で追加されました。現在の保存形式は9です。

### 完了後のプレビューと光の演出

未完了のカードにカーソルを合わせると、そのステップを完了したときに新しく着手できる後続カードと線が光り、左上に件数が表示されます。合流先に別の未完了の前提が残る場合は光りません。非表示の後続も件数に含め、非表示分を併記します。

ステップを完了すると、解放される後続への線に沿って光が流れ、到着先の輪郭がふわっと点灯します。複数選択の一括完了にも対応しています。プレビューは保存内容やUndo履歴を変更せず、演出はUndo・タブ切り替え・ウィンドウ非アクティブ化で解除されます。Windowsでアニメーションを無効にしている場合は、移動する光を省きます。

### 枝を部品として再利用する

1. 再利用したいカードを複数選択します。枝全体なら、起点を右クリック → **この枝を選択**。
2. 右クリック → **選択範囲を部品として保存…** で名前を付けて保存します。ブロックの見出しから **部品として保存…** を選ぶと、中の全ステップが対象です。
3. **ステップ → 部品ライブラリ…**（または背景の右クリック）で一覧を開き、部品をキャンバスへドラッグします。**配置する** ボタンでも配置できます。

- 選択範囲内の分岐・合流、相対配置、線の通過点、ブロック、メモ・見積もり・タグ・種別を引き継ぎます。範囲外との接続は含みません。
- 配置したステップは未着手・期限なし・位置固定なしで始まります。毎回新しいIDを発行するため、元の部品や以前に配置したものと編集内容は連動しません。
- 配置した全ステップを選択します。既存カードに重なる場合は、まとまりのまま下の空き領域へずらします。フォーカス表示中は解除して配置先を見えるようにします。
- 配置は **Ctrl+Z** 1回でまとめて取り消せます。部品の保存自体はプロジェクトやそのUndo履歴を変更しません。
- 部品は `%APPDATA%\ToDoTree\Templates` に保存し、アプリを再起動した後や別のプロジェクトでも使用できます。同名で保存しても既存部品を上書きしません。

## 動かし方

必要なもの: **.NET 10 SDK**（Windows）

SDK は `global.json` の `10.0.100` を基準に、`latestFeature` で同じ 10.0 の後続 feature band も使用できます。

```powershell
cd C:\W\CSharp\WPF\ToDoTree
dotnet run --project src\ToDoTree.App
```

Visual Studio なら `ToDoTree.slnx` を開いて `ToDoTree.App` をスタートアッププロジェクトにして F5。
ソリューションは XML 形式の `.slnx` なので、Visual Studio 2022 17.14 以降（または Visual Studio 2026）が必要です。

Core のテスト（TUnit / Microsoft.Testing.Platform）:

```powershell
dotnet test
```

テストプロジェクトはそれ自体が実行ファイルなので、直接走らせることもできます。

```powershell
dotnet run --project tests\ToDoTree.Core.Tests
```

## 使い方

初回起動ではサンプルのプロジェクトが開きます。`Ctrl+N` で自分のプロジェクトを始めてください。

### 上部のメニュー

上部の操作は **ファイル**（新規・開く・保存・書き出し）、**ステップ**（追加・接続・分割・削除）、
**表示**（配置方向・カード表示・最長経路・フォーカス）にまとめています。
保存・「＋ 続き」・自動整列と、Undo / Redo・ズームは直接ボタンで操作できます。従来のショートカットも使えます。

### 基本の流れ

1. **まとめて入力**（`Ctrl+I`）に、やることを箇条書きで貼り付ける。インデントがそのまま親子になります
2. 足りないものはカードを選んで `Enter`。続きのステップが繋がって追加され、**そのカードの上で**すぐ名前が打てます
3. 打ったら `Enter`、また打って `Enter` …… で、ステップの列がどんどん伸びる
4. 分岐させたいときは分岐元を選んで `Enter`、合流させたいときはカード右端の丸から相手のカードへドラッグ
5. `Ctrl+L` で自動整列。保存先を決めたあとは自動保存されます

### 右クリックでできること

キャンバスは、押した場所によって出るメニューが変わります。

| 押した場所 | できること |
|---|---|
| 線の上 | **ここにステップを挟む**、通過点の追加・解除、**色**、この線を外す |
| ステップの上 | 続きを追加、並行して追加、ここから繋ぐ、完了 / 未着手（**1回達成**）、**繰り返しを設定 / 編集・1回戻す・解除**、この先を畳む、この筋だけ、分割、**ブロックにまとめる / に追加 / から外す**、削除 |
| ブロックの見出し | 名前を変更、**色**、中のステップを選択、ブロックを解除 |
| 背景 | ここにステップを追加、まとめて入力、自動整列、全体表示、全部開く |

「ここにステップを挟む」は、`A → B` を `A → 新しいステップ → B` に繋ぎ直します。
あとから「やっぱりこのあいだに一手要る」と気づいたときに、線を外して繋ぎ直す手間が要りません。
挟んだステップは前後のカードと重ならない場所に置かれるので、
線の上にきちんと載せたいときは `Ctrl+L` で並べ直してください。

### 回数を決めて終わらせる

「練習を 3 回する」「レビューを 2 回する」を、同じステップを 3 枚並べずに管理できます。

1. カードを選んで右クリック → **繰り返しを設定…**（右の詳細パネルのボタンからも開けます）
2. 目標回数（`2`〜`9999`）と、いまの達成回数を入れて **適用**
3. 以降はカード右下の **＋1 回**、または `Space` で 1 回ずつ進みます

カードの外側に、自分へ戻る曲線のループと `2 / 3 回` のラベルが出ます。
線上の回数を押すと設定に戻れます。ミニマル表示でもループ線と回数を表示します。
接続点から自分自身へドラッグして戻しても、同じ設定画面が開きます（依存線は作られません）。

| 操作 | できること |
|---|---|
| カードの **＋1 回** / `Space` / 右クリック → 1回達成 | 1 回だけ増やす。上限を超えず、押しっぱなしでも増えません |
| 右クリック → **1回戻す** | 1 回だけ戻す。0 回まで戻すと未着手に返ります |
| バッジ / 右クリック → **繰り返しを編集…** | 目標と達成回数をまとめて直す（0 へのリセットもここから） |
| 右クリック → **繰り返しを解除** | 回数の記録を消して、いまの状態のまま通常のステップへ戻す |
| 詳細パネルの **着手する / 取り消す・再開する** | 回数を保ったまま状態だけ動かす |

- **完了になるのは最後の 1 回だけです。** `2 / 3` の途中では後続はまだ待ちのままで、
  `3 / 3` になった瞬間に完了日時が入り、後続が着手できるようになります。
- `3 / 3` から `2 / 3` へ戻すと完了が外れ、**まだ手を付けていない後続だけ**が待ちに返ります。
  すでに進行中・完了の後続は勝手に戻しません。
- 取り消すと回数は残したまま「もう待たなくてよい」扱いになり、`取り消し・1 / 3 回`と表示します。
  再開すると回数どおりの状態（0 なら未着手、途中なら進行中、上限なら完了）に戻ります。
- 通常のステップと繰り返しを混ぜて選んで `Space` を押すと、**通常は完了・繰り返しは 1 回加算**します。
  完了済みは変わらず、取り消し中の繰り返しは対象外です。全部完了していても巻き戻しません。
- 1 回の達成・訂正・設定・解除は、それぞれ 1 回の `Ctrl+Z` で戻せます。複数選択でもまとめて 1 回です。
- 進捗の件数はステップ単位のままです。`2 / 3` 回のステップは、完了件数には入りません。
  見積りは全回分の合計として扱い、回数で自動的に掛け算はしません。
- 初版では**単一のステップだけ**が対象です。ブロック全体を N 周する設定と、
  曜日・周期による自動更新、各回の日時の記録は含みません。回数つきのステップは分割できません。

詳細は[繰り返し項目の設計](docs/REPEAT_DESIGN.md)を参照してください。

### ステップをブロックにまとめる

「ここからここまでが設計」のようなまとまりを、名前付きの囲みにできます。

1. まとめたいステップを 2 件以上選ぶ（`Ctrl+クリック` か `Alt+ドラッグ`）
2. `Ctrl+G`、または右クリック → **ブロックにまとめる**
3. 囲みが出て見出しの入力欄にカーソルが入るので、そのまま名前を打って `Enter`（`Esc` で作成ごと取り消し）

**ブロックはタスク数に含まれない、作業のまとまりです。** 繋がっていないステップ同士もまとめられます。
同じブロックに直接入っているステップを選んで `Ctrl+G` を押すと、その中に子ブロックを作れます。
ブロック自体に線をつなぐと、その全子孫ステップを対象とした依存関係になります。

| 操作 | できること |
|---|---|
| 見出しをクリック | ブロックを選ぶ（中のカードには破線の印が付きます） |
| 見出しの `▼` / `▶` | ブロックを畳む / 開く。内部の配置は維持 |
| 見出しの右クリック → このブロックに集中 / 解除 | 中と直接接続する外部ステップを表示。解除で元の表示位置・倍率へ戻る |
| ブロックの四辺の丸からドラッグ | ステップまたはブロック全体へ接続 |
| カードを `Shift`＋ドラッグ | 強調されたブロックへ所属変更。囲みの外へドロップすると所属解除 |
| 見出しをドラッグ | 中のステップを相対位置ごと、まとめて移動。近くのブロックと端・中心を揃える |
| 見出しを `Shift`＋ドラッグ | ドロップ先の子ブロックへ移籍。囲みの外なら最上位へ移動 |
| 見出しの右クリック → ブロックに入れる / 親ブロックから外す | ブロック全体の親を変更 |
| 見出しの右クリック → このブロックを包む | 同じ位置に新しい親ブロックを作成 |
| 見出しのドラッグ中に `Alt` | 吸着を解除して自由移動。離すと位置合わせを再開 |
| 見出しをダブルクリック / `F2` | 名前を書き換える（`Esc` で元の名前に戻す） |
| 中のカードをクリック | いつもどおりステップの選択に戻る |
| 右クリック → 中のステップを選択 | 所属ステップをまとめて選び直す |
| `Ctrl+Shift+G` | 囲みだけを外す（ステップと繋がりはそのまま残ります） |

- 囲みの位置と大きさは**所属ステップから毎回計算**します。カードを個別に動かせば囲みが追従します。
- 見出しを動かすと、画面内の近くのブロックと左端・中心・右端、上端・中心・下端が揃う位置へ軽く吸着し、破線のガイドを表示します。
  ズームしても吸着する距離の感覚は一定です。離れる方向へ引けば外れ、`Alt` を押せばその場で自由移動に戻ります。
  見出しでは最初から `Alt` を押してドラッグすることもできます。背景の `Alt+ドラッグ` は従来どおり矩形選択です。
  一部のステップが非表示のブロックは吸着先に含めません。ブロック移動中はズームと画面移動を止めます。
  カード単体・複数選択の移動にも同じ吸着が働きます（[カードを揃えて置く](#カードを揃えて置く)）。
- 通常のドラッグでは所属は変わりません。`Shift`を押したときだけ所属変更のプレビューが出ます。移動と所属変更を1回のUndoで戻せます。
- 未所属のステップを選んで右クリック → **ブロックに追加** で既存の囲みに入れられます。
  **ブロックから外す**は位置とステップ間の線を維持します。ブロック全体の依存条件は所属に追随します。1つのステップが入れる囲みは1つまでです。
- 所属ステップから `Enter` で足したステップ、分割で生まれたステップ、同じ囲みの中の線に挟んだステップは、
  その囲みを引き継ぎます。背景から足したステップは未所属です。
- **ブロックを選んで `Ctrl+L`**（または見出しを右クリック →「中を整列」）で、**中だけを並べ直せます**。
  見出しの位置・外のカード・拡大率・画面の位置はそのままです。詳しくは次の節に書きました。
- ブロックを選んでいないときの `Ctrl+L`（全体整列）は**ブロックの中身を動かしません**。
  未所属のステップだけを、囲みに重ならないよう並べます。
- 完了を隠す・枝を畳むなどで一部が見えなくなると、見出しが「表示 3 / 全 5 件」になり、
  見えないものを動かさないようにブロックの移動を止めます。全部隠れたときは囲みも消えます。
- 作成・命名・移動・所属変更・解除は、どれも 1 回の `Ctrl+Z` で戻せます。途中で `Esc` を押した操作や、
  結果が変わらなかった移動では、履歴も未保存の印も増えません。
- Markdown / Mermaid の書き出しに囲みは含まれません（ステップと繋がりだけが出ます）。

### ブロックをつないで工程を管理する

- **設計ブロック → 実装ブロック**：設計の全ステップが片付くまで、実装は待ちになります。
  内部の順序も守り、複数の先行があればすべての完了を待ちます。「取り消し」は既存のステップ接続と同じく片付いたものとして扱います。
- **ステップ → ブロック**、**ブロック → ステップ**も接続できます。後から所属を変更すると条件も変わります。
  接続や所属変更で循環が生まれる場合は、理由を表示して変更を取り消します。
- 折りたたんでもブロック全体への線は実線で残ります。内部ステップへの個別接続は破線で表示します。
  破線の右クリック → **内部ステップを表示**から開くと、個別の線を編集できます。
- ブロックを解除すると、ブロックへの線をその時点の所属ステップへの接続へ置き換え、着手条件を維持します。
  最後の所属ステップを外して空になった場合は、そのブロックとブロックへの線を取り除きます。
- 作業開始後に未完了の先行が追加されても状態を戻さず、**進行中・先行に未完了あり**と表示します。
- 集中表示では対象ブロックを一時的に開きます。解除すると元の折りたたみ・表示絞り込み・位置・倍率へ戻ります。
- 折りたたみは保存されます。集中表示はタブ内の一時状態です。
- Markdown / Mermaidではブロックへの接続をステップ間の依存関係へ展開して出力します。

詳細は[ブロック接続と表示の仕様](docs/BLOCK_CONNECTIONS.md)を参照してください。

### 色で見分ける

大きくなってきたら、囲みと線に色を付けて「どの一帯が何の話か」を名前を読まずに分かるようにできます。

| 操作 | できること |
|---|---|
| ブロックの見出しを右クリック → **色** | その囲みの背景・枠・見出しの色を選ぶ |
| 線を右クリック → **色** | その線と矢印の色を選ぶ |
| 一覧のいちばん上の **既定** | 色を外して元に戻す |

用意してある色は灰・赤・橙・黄・緑・青緑・青・紫・桃の 9 色です。
いま付いている色には一覧でチェックが付きます。意味は決めていないので、好きに割り当ててください。

- **色は飾りです。** 付けても外しても、依存関係・着手可能判定・進捗・最長経路・完了予測は変わりません。
- 畳んだブロックへまとめられた線には色を付けられません（複数本が同じ場所に重なるためです）。
  ブロックを開いてから選んでください。
- **状態の合図が優先されます。** 選んでいる線、最長経路の線、選択中のステップに繋がる線は、
  色を付けていても従来どおりの状態色で描きます。先行が片付いた線は、その色のまま薄くなります。
- 色を付けたブロックを選ぶと、枠はアクセント色に変わり、背景は色を保ったまま濃くなります。
  どの色でも「いま選んでいる」の見え方は同じです。
- 明るい配色と暗い配色で、それぞれ見やすい値を用意してあります。切り替えても付けた色は残ります。
- ミニマップの囲みの外周にも同じ色が出ます。
- 色の変更は 1 回の `Ctrl+Z` で戻せます。同じ色を選び直したときは履歴も未保存の印も増えません。
- 部品として保存すると、囲みと線の色も一緒に残ります。
- Markdown / Mermaid の書き出しに色は含まれません。

### ブロックの中を並べ直す

ブロックの中でステップを足したり分割したりして散らかったら、1 操作で読みやすい配置へ戻せます。

| 入力 | 対象 |
|---|---|
| ブロックの見出しを右クリック →「中を整列」 | そのブロックの中だけ |
| ブロックを選んで `Ctrl+L` | 選んでいるブロックの中だけ |
| 何も選ばずに `Ctrl+L` | 従来どおり全体（ブロックの中は動きません） |
| ツールバーの整列ボタン | ブロック選択中は「中を整列」、それ以外は「自動整列」 |
| 表示メニューの「全体を整列」 | 選択に関係なく全体 |

守っていること:

- **見出しの位置が動きません。** 囲みの左上をそのままに、中のカードだけが並び直します。
- **外は動きません。** 外のカードも、他のブロックも、所属も、繋がりも、位置固定も変わりません。
- **画面が飛びません。** 全体表示にはならず、拡大率と見ている場所を保ったまま、そのまま編集を続けられます。
- **手動の通過点はそのままです。** 座標も順序も滑らかさも保つので、線が遠回りに見えることがあります。
  気になるときは線を右クリック →「通過点をすべて解除」で自動経路に戻せます。
- 並びは依存関係の順で決まります。同じ構造で 2 回続けて実行しても結果は変わらず、履歴も増えません。
- ブロックの中の直接の繋がりだけを見ます。外を経由して戻る筋（中 → 外 → 中）は並びに持ち込みません。

初版でできないこと（メニューには理由が出ます）:

| 状態 | 理由 |
|---|---|
| ステップが 1 件以下 | 並べるものがありません |
| 一部のステップが隠れている | 見えないものを動かさないため、すべて表示してから |
| 位置を固定したステップがある | 固定を黙って外さないため、先に解除してから |
| 並べ直すと外のカードや他の囲みに重なる | 何も変えずに中止します。ブロックを広い場所へ移してから |
| 名前を打っている最中・接続中・ドラッグ中 | 手を離してから |

### 複数のプロジェクトを開く

「新規」または「開く」で、現在のプロジェクトを閉じずに別のタブを追加できます。
タブをクリックして切り替え、右側の `×` で閉じます。同じファイルをもう一度開いた場合は、
重複したタブを作らず、すでに開いているタブへ移動します。

選択中のステップ、検索・絞り込み、Undo / Redo、キャンバスの位置と拡大率はタブごとに独立しています。
保存や書き出しなどの操作は、現在選択しているタブが対象です。終了時に開いていた保存済みプロジェクトと
未保存プロジェクトの復旧データは、次回起動時にまとめて復元されます。

### 表示を軽くする

ステップが増えて画面が重くなったら、`Ctrl+Shift+M` で **ミニマル表示** に切り替えます。
カードが **丸ひとつ** になり、あとは線だけになります。同じ広さに、ずっと多くのステップが収まります。

名前は、カーソルを乗せたときと選んでいるときに、丸の右横に出ます。
出ている名前の右端では、そのまま畳む・開くもできます。状態は丸の描き分けで分かります。

| 丸 | 意味 |
|---|---|
| 中抜き・細い枠 | 待ち（先行が残っている） |
| 中抜き・太い緑の枠 | 着手できる |
| 塗りつぶし | 進行中 |
| 灰色の塗りつぶし | 完了・取り消し（名前に取り消し線） |

外側の輪は、オレンジなら最長経路、それ以外は種別（起点・節目・ゴール）です。
期限を過ぎている、あるいは要着手のステップは、丸の右肩に小さな点が付きます。
この先を畳んでいるステップは、外側が破線の輪になります。

切り替えても**位置は動きません**。詰めたいときは `Ctrl+L` で、この表示に合った間隔に並び直します。
もう一度 `Ctrl+Shift+M` でカード表示に戻ります。選んだ表示は次の起動にも引き継がれます。

### 次に何をやるか

左パネルの一番上に「次にやること」が 3 件、**理由付き**で出ます。
着手できるステップが複数あるとき、次の材料から順位を決めています。

- 最長経路（クリティカルパス）の上にあるか
- 期限が近いか、過ぎているか
- 終えると何個のステップが動き出すか（＝詰まりの解消度）
- この先にどれだけ仕事が控えているか

ツールバーの「最長経路」を押すと、全体の背骨になっている鎖がオレンジで浮かび上がります。
期限から逆算した開始日を過ぎているステップには「要着手」の印が付きます。

下のバーには **完了見込み** が出ます。残っている見積りを、これまで実際に片付けてきたペースで割った予測です
（完了記録が 2 件に満たないうちは「1 日 4 時間」として計算します）。
ゴールに期限を付けておくと、間に合うか・何日足りないかまで出ます。

ステップを完了すると、そのとき新しく着手できるようになったステップの名前が下に出ます。

| Markdown / Mermaid で書き出す | `Ctrl+Shift+E` |
| 続きのステップを追加 | `Enter` |
| 並行のステップを追加（同じ先行にぶら下げる） | `Shift+Enter` |
| 名前を編集（カードの上で直接） | `F2` / カードをダブルクリック |
| 完了 / 未着手 を切り替え（回数つきなら 1 回達成） | `Space` |
| 削除（前後は自動で繋ぎ直し） | `Delete` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Y` |
| 隣のステップへ移動 | `←` `→` `↑` `↓` |
| ここから繋ぐ（相手を選んで `Enter`） | `Ctrl+E` |
| すべて選択 / この枝をまとめて選択 | `Ctrl+A` / `Ctrl+Shift+↓` |
| 選んだステップをブロックにまとめる | `Ctrl+G` |
| ブロックの囲みを外す | `Ctrl+Shift+G` |
| ブロックの中を整列（ブロック選択中の `Ctrl+L`） | `Ctrl+L` |
| 自動整列 | `Ctrl+L` |
| 全体表示 | `Ctrl+0` |
| 拡大 / 縮小 | `Ctrl++` / `Ctrl+-` / ホイール |
| 新規 / 開く / 保存 / 名前を付けて保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 明るい配色 / 暗い配色 を切り替え | `Ctrl+Shift+D` |

※ `Enter` `Space` `Delete` `F2` はキャンバスにフォーカスがあるときのキーです（`Enter` はタイトル入力欄でも効きます）。
※ ブロックを選んでいるあいだ、`Enter` `Space` `Delete` はステップの追加・完了・削除には使いません。
囲みを外すのは `Ctrl+Shift+G` と右クリックのメニューだけです。`F2` は見出しの名前編集になります。

### マウス操作

- カードをドラッグ … 移動（複数選んでいれば、まとめて動きます）。近くのカードや囲みと端・中心が揃います
- **カードのドラッグ中に `Alt`** … 吸着を解除して自由移動
- カードをダブルクリック … その場で名前を書き換える
- カード右端の丸からドラッグ … 別のステップへ繋ぐ（循環する繋ぎ方は自動で拒否されます）
- **線をクリック** … その繋がりを選ぶ。`Delete` で外せます
- **Ctrl+クリック** … 選択に足す / 外す
- **Alt+ドラッグ** … 矩形で囲んでまとめて選ぶ（背景から始めたときだけ）
- 背景をドラッグ / 中ボタンドラッグ … 画面を動かす
- ホイール … カーソル位置を中心に拡大縮小
- **ブロックの見出しをドラッグ** … 中のステップをまとめて移動（ドラッグ中に `Esc` で取り消し）
- 左の一覧をダブルクリック … そのステップの位置へ移動
- 右下のミニマップをクリック … そこへ飛ぶ（囲みの外周も薄く出ます）

複数選んだ状態で `Space` を押せばまとめて完了に、`Delete` でまとめて削除できます。

### カードを揃えて置く

カードをドラッグすると、画面内の他のカードやブロックの囲みと**左端・中心・右端、上端・中心・下端**が
揃う位置へ軽く吸着し、破線のガイドが出ます。カード表示でもミニマル表示でも同じように働きます。

| 操作 | 動き |
|---|---|
| カードをドラッグ | 近くのカード・囲みと端や中心が揃う位置へ吸着 |
| ドラッグ中に `Alt` | 吸着を解除して自由移動。離すと位置合わせを再開 |
| 揃った位置からさらに引く | 少し引けば外れます |

- 複数選んでまとめて動かすときは、**選んだカード全体の外接矩形**で揃えます。カード同士の相対位置は崩れません。
- 動かすカードが入っている囲みには吸着しません（カードと一緒に動くため）。
  同じ囲みの中でも、動かさないカードには揃います。
- ズームしても吸着する距離の感覚は一定です。最初から `Alt` を押したままドラッグすれば、吸着なしで動かせます。
  背景からの `Alt+ドラッグ` は従来どおり矩形選択です。
- 吸着していても、`Shift` を押しながら離せばこれまでどおりドロップ先のブロックへ所属を変更できます。
- カードの移動中は、ズームと画面移動を止めます。

### 線の迂回

線が途中のカードにぶつかる場合は、カードの周囲に余白を取り、空いている水平・垂直の通路へ迂回します。
単純な迂回で抜けられない場合は、複数回曲がる通路も探索し、距離と曲がり角の少なさを考慮して選びます。
障害物がなければ従来の曲線を使います。指定した接続辺は維持し、移動・表示切り替えに合わせて経路を更新します。
迂回した線もクリックで選択でき、接続先に重ねたプレビューにも同じ経路を表示します。
カードの重なりなどで候補の通路が確保できない場合は元の曲線を表示します。線同士の交差解消は対象外です。

### ブロックに接続点を追加する

- ブロックの枠または見出しを右クリック → **ここに接続点を追加**。近い辺に、中心に印のある丸を置きます。
- 接続点からドラッグして、ステップ・ブロック・別の接続点へ繋げます。既存の接続用の丸から、この点へ繋ぐこともできます。
- **Alt＋ドラッグ**で接続点を枠に沿って移動します。`Esc`で取消。点の右クリックまたは選択後の`Delete`で削除します。
- 既存の線を右クリック → **接続元の接続点／接続先の接続点**で、接続点または標準位置へ付け替えられます。

接続点はブロックの移動・サイズ変更に追従し、折りたたんだときも同じ辺の同じ割合の位置に表示します。
点を削除しても線と依存関係は残り、同じ辺の標準位置へ戻ります。複数の線で同じ点を共有できます。
追加・移動・削除・付け替えは保存とUndo/Redoに対応し、線の通過点とも併用できます。
接続点は線の表示位置の指定です。接続による着手条件は従来どおりブロック全体に適用されます。

### 線に通過点を置く

- 線を右クリック → **ここに通過点を追加**（線のダブルクリックでも追加）
- 小さな丸をドラッグ → 通過する位置を移動
- 丸を右クリック → **滑らかにする** をチェックすると、その点を曲線で通過（外すと角に戻る）
- 丸を選んで `Delete`、または丸を右クリック → **この通過点を削除**
- 線の右クリック → **通過点をすべて解除** で自動経路に戻す

複数の通過点を指定できます。途中への追加は線上の位置に応じた順序で入り、選択中の点は塗りつぶして表示します。
点はキャンバス上の固定位置で、タスクの移動や自動整列では動きません。全体表示には通過点も含みます。
通過点は線の表示専用で、タスクや依存関係は増えません。保存・再読み込みと Undo / Redo に対応します。
滑らかさは点ごとに保存され、移動しても維持されます。滑らかにした点の前後は、隣の通過点またはカードまで区間全体を曲線でつなぎます。カードに近い場所では曲線の膨らみを抑え、回避できない区間は迂回路を使います。
各点の間ではカードを避ける経路を探します。カード内部などに点を置いて回避できない場合も、指定位置を優先します。

### 数が増えてきたら

- **カード隅の `▾`** … その先を畳みます。畳んだ数が `▸ 12` のように出ます。
  別の枝からも辿れるステップは畳まれません（合流の先は消えません）
- **「この筋だけ」** … 選んだステップの上流・下流だけを残して、他を隠します
- **「完了したものを隠す」** … 済んだステップをキャンバスと一覧の両方から外します
- **タグの絞り込み** … ツールバーのタグを選ぶと、該当しないステップが薄くなります
- **ブロック** … 一帯をまとめて名前を付け、見出しをつかんで丸ごと動かします（`Ctrl+G`）。
  中が散らかったら、見出しを右クリック →「中を整列」で並べ直せます
- **ミニマップ** … 右下に全体図。青い枠がいま見ている範囲です

### 明るい配色と暗い配色

右上の月／太陽のボタン（`Ctrl+Shift+D`）で切り替えます。選んだ配色は次回起動時も保たれます。
色はすべて `Themes/Palette.Light.xaml` と `Palette.Dark.xaml` に集めてあるので、
自分好みの色にしたいときはこの 2 つを書き換えるだけで、画面全体（カード・線・ミニマップまで）に反映されます。

### 色の意味

| 見た目 | 意味 |
|---|---|
| 緑の枠 | **着手できる**（先行がすべて片付いている） |
| 青の枠 | 進行中 |
| 灰色の枠 | 待ち（未完了の先行がある） |
| 取り消し線・薄い | 完了 / 取り消し |
| 赤い「期限超過」 | 期限を過ぎている |
| オレンジの「要着手」 | 逆算した開始日を過ぎている（このままでは間に合わない） |
| オレンジの太い枠・線 | 最長経路の上（表示を切り替えたとき） |
| カード左の色帯 | 種別（スタート / ステップ / 節目 / ゴール） |

### 外に持ち出す

「書き出す」（`Ctrl+Shift+E`）で **Markdown** か **Mermaid** に出せます。
Markdown には進捗・次にやること・全体図（Mermaid）・直近 7 日で終えたこと・全ステップ一覧が入るので、
週報や進捗共有にそのまま使えます。「図をコピー」ならクリップボードに Mermaid が入り、
GitHub や Notion に貼るだけで図が出ます。

### 大きすぎるステップを割る

ステップを選んで「分割」を押すと、箇条書きで細かいステップに割れます。
割ったステップは元のステップの下に入り、**元の後続にはそのまま繋がる**ので流れが切れません。
回数で完了するステップは分割できません。先に繰り返しを解除してください。

## 保存形式

1 プロジェクト = 1 ファイルの JSON（`*.todotree.json`）。人が読める形なので Git で差分管理もできます。
保存は一時ファイルに書いてから本体を置き換えます。既存の本体は `.bak` に直前の1世代だけ残ります。

現在の `schemaVersion` は `9` です。`2`でブロック、`3`でしおり、`4`でブロック接続と折りたたみ、
`5`で個別色、`6`で回数で完了する項目、`7`でブロックの接続点、`8`でブロックの親子関係を追加しました。
旧形式は読み込み時に移行し、次の保存で現行形式になります。
古いアプリは未対応の新形式を拒否し、情報を落とした上書きを防ぎます。

全タブの変更を **5秒周期で確認** し、保存先が決まっていれば本体へ自動保存します。
保存先未指定の変更済みタブは `%APPDATA%\ToDoTree\autosave\<タブID>.todotree.json` へ退避します。
ブロックの移動・命名中、接続点の移動中とカードのドラッグ中は自動保存を見送ります。

開いていたファイル、タブの順序、選択中のタブ、キャンバスの表示位置は
`%APPDATA%\ToDoTree\settings.json` に覚えていて、次回起動時に復元されます。

「保存しない」で閉じても、すでに自動保存した内容は元に戻りません。
自動保存失敗の通知、日時別のバックアップ、`.bak`からの自動復元は未実装です。
保存対象・終了時の扱い・復旧方法は[保存と復旧](docs/STORAGE.md)にまとめています。
