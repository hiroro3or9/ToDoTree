# ToDoTree

ゴールまでの道のりを **分岐と合流のあるグラフ（DAG）** で書き出して進める、C# / WPF の Todo 管理アプリ。

マインドマップのように枝を伸ばし、Git のブランチのように分かれた作業を合流させられます。
「いま着手できるステップ」はグラフから自動で判定されるので、次に何をやればいいか迷いません。

## 動かし方

必要なもの: **.NET 8 SDK**（Windows）

```powershell
cd C:\W\CSharp\WPF\ToDoTree
dotnet run --project src\ToDoTree.App
```

Visual Studio なら `ToDoTree.sln` を開いて `ToDoTree.App` をスタートアッププロジェクトにして F5。

Core のテスト（外部パッケージ不要）:

```powershell
dotnet run --project tests\ToDoTree.Core.Tests
```

## 使い方

初回起動ではサンプルのプロジェクトが開きます。`Ctrl+N` で自分のプロジェクトを始めてください。

### 基本の流れ

1. **まとめて入力**（`Ctrl+I`）に、やることを箇条書きで貼り付ける。インデントがそのまま親子になります
2. 足りないものはカードを選んで `Enter`。続きのステップが繋がって追加され、**そのカードの上で**すぐ名前が打てます
3. 打ったら `Enter`、また打って `Enter` …… で、ステップの列がどんどん伸びる
4. 分岐させたいときは分岐元を選んで `Enter`、合流させたいときはカード右端の丸から相手のカードへドラッグ
5. `Ctrl+L` で自動整列。保存先を決めたあとは自動保存されます

### 次に何をやるか

左パネルの一番上に「次にやること」が 3 件、**理由付き**で出ます。
着手できるステップが複数あるとき、次の材料から順位を決めています。

- 最長経路（クリティカルパス）の上にあるか
- 期限が近いか、過ぎているか
- 終えると何個のステップが動き出すか（＝詰まりの解消度）
- この先にどれだけ仕事が控えているか

ツールバーの「最長経路」を押すと、全体の背骨になっている鎖がオレンジで浮かび上がります。
期限から逆算した開始日を過ぎているステップには「要着手」の印が付きます。

下のバーには **完了見込み** が出ます。残っている見積りを、これまで実際に片付けてきたペースで割った予測です
（完了記録が 2 件に満たないうちは「1 日 4 時間」として計算します）。
ゴールに期限を付けておくと、間に合うか・何日足りないかまで出ます。

ステップを完了すると、そのとき新しく着手できるようになったステップの名前が下に出ます。

### キー操作

| 操作 | キー |
|---|---|
| 箇条書きをまとめて取り込む | `Ctrl+I` |
| Markdown / Mermaid で書き出す | `Ctrl+Shift+E` |
| 続きのステップを追加 | `Enter` |
| 並行のステップを追加（同じ先行にぶら下げる） | `Shift+Enter` |
| 名前を編集（カードの上で直接） | `F2` / カードをダブルクリック |
| 完了 / 未着手 を切り替え | `Space` |
| 削除（前後は自動で繋ぎ直し） | `Delete` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Y` |
| 隣のステップへ移動 | `←` `→` `↑` `↓` |
| ここから繋ぐ（相手を選んで `Enter`） | `Ctrl+E` |
| すべて選択 / この枝をまとめて選択 | `Ctrl+A` / `Ctrl+Shift+↓` |
| 自動整列 | `Ctrl+L` |
| 全体表示 | `Ctrl+0` |
| 拡大 / 縮小 | `Ctrl++` / `Ctrl+-` / ホイール |
| 新規 / 開く / 保存 / 名前を付けて保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |

※ `Enter` `Space` `Delete` `F2` はキャンバスにフォーカスがあるときのキーです（`Enter` はタイトル入力欄でも効きます）。

### マウス操作

- カードをドラッグ … 移動（複数選んでいれば、まとめて動きます）
- カードをダブルクリック … その場で名前を書き換える
- カード右端の丸からドラッグ … 別のステップへ繋ぐ（循環する繋ぎ方は自動で拒否されます）
- **線をクリック** … その繋がりを選ぶ。`Delete` で外せます
- **Ctrl+クリック** … 選択に足す / 外す
- **Alt+ドラッグ** … 矩形で囲んでまとめて選ぶ
- 背景をドラッグ / 中ボタンドラッグ … 画面を動かす
- ホイール … カーソル位置を中心に拡大縮小
- 左の一覧をダブルクリック … そのステップの位置へ移動
- 右下のミニマップをクリック … そこへ飛ぶ

複数選んだ状態で `Space` を押せばまとめて完了に、`Delete` でまとめて削除できます。

### 数が増えてきたら

- **カード隅の `▾`** … その先を畳みます。畳んだ数が `▸ 12` のように出ます。
  別の枝からも辿れるステップは畳まれません（合流の先は消えません）
- **「この筋だけ」** … 選んだステップの上流・下流だけを残して、他を隠します
- **「完了したものを隠す」** … 済んだステップをキャンバスと一覧の両方から外します
- **タグの絞り込み** … ツールバーのタグを選ぶと、該当しないステップが薄くなります
- **ミニマップ** … 右下に全体図。青い枠がいま見ている範囲です

### 色の意味

| 見た目 | 意味 |
|---|---|
| 緑の枠 | **着手できる**（先行がすべて片付いている） |
| 青の枠 | 進行中 |
| 灰色の枠 | 待ち（未完了の先行がある） |
| 取り消し線・薄い | 完了 / 取り消し |
| 赤い「期限超過」 | 期限を過ぎている |
| オレンジの「要着手」 | 逆算した開始日を過ぎている（このままでは間に合わない） |
| オレンジの太い枠・線 | 最長経路の上（表示を切り替えたとき） |
| カード左の色帯 | 種別（スタート / ステップ / 節目 / ゴール） |

### 外に持ち出す

「書き出す」（`Ctrl+Shift+E`）で **Markdown** か **Mermaid** に出せます。
Markdown には進捗・次にやること・全体図（Mermaid）・直近 7 日で終えたこと・全ステップ一覧が入るので、
週報や進捗共有にそのまま使えます。「図をコピー」ならクリップボードに Mermaid が入り、
GitHub や Notion に貼るだけで図が出ます。

### 大きすぎるステップを割る

ステップを選んで「分割」を押すと、箇条書きで細かいステップに割れます。
割ったステップは元のステップの下に入り、**元の後続にはそのまま繋がる**ので流れが切れません。

## 保存形式

1 プロジェクト = 1 ファイルの JSON（`*.todotree.json`）。人が読める形なので Git で差分管理もできます。
保存は一時ファイルに書いてから置き換えるので、途中で落ちても元ファイルは壊れません（`.bak` も残ります）。

保存先が決まっていれば **5 秒ごとに自動保存** します。まだ保存していない作業は
`%APPDATA%\ToDoTree\autosave.todotree.json` に退避され、次回起動時に復元されます。

最後に開いていたファイルは `%APPDATA%\ToDoTree\settings.json` に覚えていて、次回起動時に自動で開きます。

## 構成

```
ToDoTree.sln
├ src/ToDoTree.Core   … 画面に依存しないロジック（net8.0）
│   ├ Models          … TodoNode / TodoEdge / TodoProject
│   ├ Graph           … DAG 操作、循環検出、着手可能判定、進捗、クリティカルパス
│   ├ Layout          … 階層レイアウト（Sugiyama 風）
│   └ Storage         … IProjectStore と JSON 実装
├ src/ToDoTree.App    … WPF（net8.0-windows、MVVM、外部パッケージ無し）
│   ├ ViewModels      … MainViewModel / NodeViewModel / EdgeViewModel
│   ├ Controls        … GraphView（ズーム・パン・ドラッグ）、EdgeLayer（線の描画）
│   └ Themes          … 配色とスタイル
└ tests/ToDoTree.Core.Tests … Core のテスト（28 件）
```

保存層は `IProjectStore` で抽象化してあるので、SQLite に替えたくなったら実装をひとつ足すだけです。

## いまはできないこと（次の候補）

- 線そのものをクリックして選択・削除（いまは右の詳細パネルの ✕ から外します）
- カード上での直接編集（いまは右の詳細パネルで書き換えます）
- 複数選択・まとめて移動
- フォーカスモード、完了の折りたたみ、ミニマップ
- ガントチャート出力、画像の書き出し
- 今日やることへの切り出し、テンプレート
