# ブロック接続と表示

更新日: 2026-09-08  
状態: 実装済み

## 接続の意味

ブロックはタスク数や工数へ加算しない。接続の端点にはステップIDとブロックIDを使える。
`Aブロック → Bブロック` はAの全所属ステップからBの全所属ステップへの依存条件として計算する。
先行は既存ルールと同じく完了・取り消しで解消し、内部の順序と別の先行条件も維持する。

保存する線はブロックを端点とした1本のまま。`TodoGraph` の隣接索引と `Edges` は計算用に展開し、
画面では `TodoProject.Edges` を使う。計算用の辺には保存元の線IDを付け、最長経路の強調にも使う。
所属変更後は索引を再構築する。タスクの状態を自動的に書き換えることはない。
進行中のステップに未完了の先行が増えた場合は、状態表示に「先行に未完了あり」を添える。

新規接続と所属の追加・移籍は循環を拒否する。移籍はコピーで検証してから反映する。
失敗したドラッグでは、位置・所属・履歴・Redo・未保存状態を変更前へ戻す。

## 折りたたみと集中表示

- 見出しの三角と右クリックメニューから折りたたむ。内部の座標は変更しない。
- 畳んだブロックは固定サイズの見出しカードとして残り、完了件数を表示する。
- ブロック全体への接続は実線。非表示の内部ステップを端点に持つ線は破線でブロック端へ投影する。
- 実線と破線は接続位置をずらす。同じブロック内の線は畳んでいる間は非表示。
- 破線は右クリックの「内部ステップを表示」で開いてから編集する。投影中は通過点も隠す。
- 集中表示は所属ステップと直接の先行・後続を残す。対象ブロックを一時的に開き、他の表示フィルターより優先する。
- 集中表示の解除で元の折りたたみ、フィルター、表示位置、倍率へ戻る。タブごとに独立する。
- 集中表示中に対象を畳む操作は、集中表示を終了して折りたたむ。
- ブロックを畳んだことによる非表示だけなら見出しでまとめて移動できる。
  完了非表示などで所属の一部しか対象にならない場合は、従来どおり移動しない。
- 隠れたステップを選ぶ操作やしおりからの復帰では、そのブロックを開いて表示する。

## 所属をドラッグで変える

通常のカードドラッグは位置だけを変える。Shiftを押すと追加先を強調し、離すと移籍する。
囲みの外で離すと所属を外す。候補判定にはドラッグ開始時の囲みを使い、所属カードの移動に
追従して広がった囲みを追加先と誤認しないようにする。複数選択をまとめて移籍できる。
重なった囲みは面積の小さいものを優先する。

位置・内部線の通過点・所属を同じトランザクションに含め、Undo 1回で戻す。
Esc、非アクティブ化、キャプチャ喪失、タブ切替は取消。確定前は自動保存を見送る。
Shiftを離すと所属変更をやめ、位置の移動だけを確定する。

## 解除・保存・再利用

囲みの解除では、その囲みを端点とする線を所属ステップへ展開する。他のブロック端点は維持する。
重複するステップ間の線を増やさず、解除前後の依存条件を保つ。
最後の所属ステップを外す・削除する操作では、空になったブロックとその接続を取り除く。

形式4で `TodoBlock.IsCollapsed` とブロック端点を追加した。現在の形式5は個別色も保存する。
旧形式は読み込み時に移行し、不正な端点・二重所属・循環を持つデータは読み込みを拒否する。
部品はブロック接続も保存・再配置し、配置時は新しいIDで未着手・展開状態にする。
Markdown / Mermaidには展開したステップ間依存を出力する。

## 検証

`BlockConnectionTests` で複数先行、内部順序、循環拒否、移籍の原子性、解除、削除、保存、部品、
書き出しと異なるサイズの端点の経路を確認する。
`ToDoTree.App.SmokeTests` はWPF連携と明暗テーマの描画を確認する。
実マウス・IME・OSの表示倍率の確認は[開発ガイド](DEVELOPMENT.md)に従う。
