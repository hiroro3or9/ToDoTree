# 開発ロードマップ

更新日: 2026-09-08

## 優先方針

**操作感と手触りの向上を最優先する。**
書く・つなぐ・動かす・直す操作を途切れさせず、依存関係のある計画を気軽に維持できることを目指す。
機能を追加するときも、操作回数が減るか、選択とフォーカスが自然につながるか、Undoで戻せるかを基準にする。

## 実装済みの範囲

| 領域 | 現在使える機能 |
|---|---|
| 入力・編集 | 連続追加、カード上の直接編集、アウトライン一括入力、ステップ分割 |
| 接続 | 分岐・合流、循環拒否、キーボード接続、線へのステップ挿入 |
| 選択・移動 | 複数選択、矩形選択、枝の選択、一括移動・状態変更・削除 |
| 見渡す | 自動整列、枝の折りたたみ、フォーカス、完了非表示、検索・タグ絞り込み、ミニマップ |
| 表示 | ライト／ダーク、手動のミニマル表示 |
| 線 | カードを避ける迂回、手動通過点、点ごとの滑らかさ |
| 進める | 着手可能判定、理由付きの次の行動、最長経路、期限からの逆算、完了予測 |
| 文書管理 | 複数タブ、手動／自動保存、未保存タブの退避、セッション復元 |
| 作業のしおり | プロジェクトごとの再開カード・メモ、起動時の移動、カード上の旗、Undo |
| 書き出し | Markdown／Mermaid、完了記録を含むMarkdown出力 |
| ブロック | 作成・命名、Shiftドラッグで所属変更、まとめて移動、折りたたみ、集中表示、ブロックへの依存接続、解除 |
| ブロック内整列 | 内部だけ整列、見出し位置と外部ノードを保持、衝突する候補を拒否 |
| ブロック吸着 | 端・中心への吸着、破線ガイド、Altで自由移動、ズームに応じた距離換算 |
| カード吸着 | カード単体・複数選択を外接矩形で他のカード・囲みへ吸着。カード表示とミニマル表示の両方 |
| 色分け | ブロックと線に9色のプリセットを個別指定、ライト／ダーク両対応、Undo |
| 回数で完了する項目 | 目標回数と達成回数、1回達成・1回戻す・訂正・解除、取り消しと再開、自己接続からの設定 |

詳細な操作は[README](../README.md)、保存の条件と限界は[保存と復旧](STORAGE.md)を参照。

「完了非表示」は完了部分を1枚の集約カードへ変換する機能ではない。
「手動のミニマル表示」はズーム連動の自動切替ではない。
ブロックの折りたたみ・集中表示・接続・入れ子は実装済み。

## 次に優先する改善

| 優先 | 候補 | 得たい効果・確認点 |
|---|---|---|
| 1 | 既存操作の実マウスでの調整 | 吸着の強さ、Alt、ドラッグ取消、IME、フォーカス、Undoの単位を確認 |
| 2 | カード吸着の距離の詰め | 揃え先が多くて鬱陶しくないかを実操作で見て、直交方向の候補範囲から調整する |
| 4 | 大きなグラフの性能と視認性 | 移動・ズーム・迂回の時間を計測し、必要な箇所を改善 |
| 5 | 整列できない場合の配置支援 | 周囲との衝突理由を分かりやすくし、移動先プレビューを検討 |

優先順位は使用中に見つかった摩擦に応じて見直す。日付や実装を確約した計画ではない。

## 保存まわりの改善候補

現在の制約は[保存と復旧](STORAGE.md)へ集約している。以下は未実装。

- 自動保存失敗の表示と、保存状態の分かりやすい案内。
- 世代別バックアップと、バックアップからの復元UI。
- 設定ファイルの原子的保存と、復旧ファイルの発見・管理。
- 複数のアプリ起動や外部編集による競合の検知。

## その後の候補

- 「今日やること」への切り出し、プロジェクト横断の一覧・検索。
- 部品ライブラリの管理機能（名前変更・削除・並べ替え）。枝／ブロックの保存と再配置は実装済み。
- 依存関係の一括編集、長期間更新されていない枝の整理支援。
- 作業可能時間・休日・実績時間を考慮した予測、残件数の推移。
- ズームに応じた情報の省略、タブのキーボード切替。
- JSON Canvas入出力、PNG出力、印刷。
- 期限通知。曜日・周期による繰り返しの自動更新、無限反復、各回の達成履歴、ブロック全体の周回。
  回数で完了する単一項目は実装済み（[繰り返し項目の設計](REPEAT_DESIGN.md)）。
