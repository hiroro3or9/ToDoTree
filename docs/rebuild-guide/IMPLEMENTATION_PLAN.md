# 段階別の実装順

01から14を順に実施する。各段階は独立した会話にし、長ければ実装項目を1つだけ進めて記録する。
番号は依存の順序で、同時に着手する指示ではない。

| 段階 | 内容 |
|---|---|
| [01](phases/01.md) | プロジェクトとモデルの土台 |
| [02](phases/02.md) | 配色とメイン画面の外枠 |
| [03](phases/03.md) | DAGの操作と状態判定 |
| [04](phases/04.md) | カード描画とCanvas操作 |
| [05](phases/05.md) | 編集・詳細・Undoと連続入力 |
| [06](phases/06.md) | JSON保存・タブ・自動保存・復旧 |
| [07](phases/07.md) | 計画・検索・表示範囲 |
| [08](phases/08.md) | 自動整列・曲線・通過点 |
| [09](phases/09.md) | ブロックの作成・移動・内部整列 |
| [10](phases/10.md) | ブロック接続・折りたたみ・入れ子・接続点 |
| [11](phases/11.md) | 吸着・個別色・ミニマル表示 |
| [12](phases/12.md) | 受信箱・チェック・作業ブロック・しおり・今日の完了 |
| [13](phases/13.md) | カードの内部ステップ |
| [14](phases/14.md) | コピーと貼り付け |

01〜06で「作って・繋いで・保存できる」まで。07〜11で計画と見た目。12で日々の運用機能。
13〜14でカードの内部ステップとコピー貼り付け。段階14の終わりに[受入確認](ACCEPTANCE.md)を通す。

## トークンを抑える進め方

- 毎回読むのは、共通指示・進捗メモ・現在の段階・その段階が指定した資料だけ。
- 1会話を「Coreのロジック」「画面への接続」「確認」のどれか1つに絞ってもよい。
- エラーは該当箇所と前後だけを渡す。成功したコードの全文を再出力させない。
- 途中の段階は完成版ではない。実データを入れるのは段階06が終わってから。

## この版で作らないもの

次の機能は意図的に外している。必要になったら、schemaVersionを上げてフィールドを足す。

回数を指定する項目（繰り返し）／プロジェクト変数／箇条書きの一括入力とMarkdown・Mermaid書出し／
部品ライブラリ／選択肢の分岐／完了した枝の標本帳と演出／作業手順の定義と実施履歴／
枝を別プロジェクトへ引っ越す機能。

これらを前提にした文言（メニュー項目など）も画面に出さない。
