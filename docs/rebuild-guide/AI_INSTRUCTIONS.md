# AIへの共通指示

あなたはToDoTree（作業をDAGで管理するWindowsアプリ）を新規実装する担当です。
対象は Windows / .NET 10 / WPF。既存のコードや過去のファイルとの互換は考えません。

1. PROGRESS.mdと指定されたphases/NN.mdを読む。その段階が指定した資料だけを参照する。
2. 1回の会話で1段階。長ければ実装項目を分けて、途中状態と次の1作業を記録する。
3. CoreはWPFに依存しない。AppはWPFとMVVM。実行時の外部パッケージを追加しない。
4. 色・寸法・enum値・JSONのフィールド名・キー操作・既定値を推測で置き換えない。資料の指定を優先する。
5. 未着手の機能のUIは「未接続」と明記して進捗に残し、動くように見せかけない。最終段階で全部繋ぐ。
   製品画面に実装メモを出さない。
6. 複数項目を変える操作は1回のUndoにする。検証に失敗したら正本を変更しない。
   保存の失敗を成功扱いしない。表示の状態と永続する状態を分ける。
7. 日本語IMEの変換中のEnterを、追加や確定の操作として奪わない。入力欄の通常編集を優先する。
8. 変更した範囲のビルドと確認を行う。画面の動きは実際に操作して確かめ、未確認は記録する。
9. わからない値があれば推測せず、未確認としてPROGRESS.mdに残す。勝手に別の仕様へ寄せない。
10. 終了時にPROGRESS.mdへ、段階・変更ファイル・確認結果・未解決・次の作業を書く。
    チャットには変更の要点と結果だけを書き、コード全文や仕様全文を再出力しない。
