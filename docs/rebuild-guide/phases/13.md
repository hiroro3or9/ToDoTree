## 実装項目（上から順に、1つずつでよい）

1. 段階01で用意した`parentTaskId`を使い、階層の取得（直接の子・子孫・祖先）と検証を実装する。
2. ダブルクリックで内部へ入り、パンくず・‹ 戻る・階層移動時の解除と全体表示を実装する。
3. 一覧・Canvas・進捗・自動整列を現在の階層に限定する。保存と削除は内部を含めて扱う。
4. 祖先の条件を着手判定に足し、子から親の状態を集計する。カードに「内部 n／m 件完了」を出す。
5. 階層をまたぐ線・ブロック、内部親の循環を拒否する。specs/04の「（段階13で追加）」の読込検証もここで実装する。

## 終了条件

- [ ] 内部へ入って戻ると、元の親カードが選ばれた状態で全体表示になる。
- [ ] 子を全部完了させると親が自動でDoneになり、1件戻すと未完了へ戻る。
- [ ] 外側の祖先がブロックされている間、内部のカードは着手できない。
- [ ] 親を削除すると内部も消え、Undoで内部ごと戻る。
- [ ] 保存して読み直しても階層が保たれ、階層をまたぐ線は拒否される。

## 確認の作り方

階層の集計（深い階層から上へ）と、循環・またぎの拒否をテストで固定する。
