## 前提

## 実装項目（上から順に、1つずつでよい）

1. Core / App / テストのソリューションを新規作成し、参照方向とビルドを通す。
2. 保存モデルとenumを実装する（Nodeの`parentTaskId`も含む。使うのは段階13）。null代入で空配列になるコレクションもここで決める。
3. モデルの深いコピー（DeepClone）を実装する。Undoの土台になる。
4. ObservableObjectとRelayCommandを用意し、空のWPFウィンドウを起動する。
5. サンプル用の最小DAG（A→B、A→C、B/C→Goal）をメモリ上で作れるようにする。
