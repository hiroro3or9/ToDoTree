## 実装項目（上から順に、1つずつでよい）

1. 層分けと交差低減の自動整列を、Card/Minimal両方の寸法で実装する。
2. 出発辺・到着辺（Auto/Right/Top/Bottom/Left）を守る曲線と矢印を実装する。
3. 通過点の追加・ドラッグ・削除・全解除・滑らかさ切替とヒットテストを実装する。
4. 左右／上下の向き切替と、固定カードを動かさない自動整列を繋ぐ。

## 終了条件

- [ ] 上下方向に切り替えてもカードが重ならない。
- [ ] 通過点を変えても依存関係は変わらず、Undoで形が戻る。
- [ ] 逆向き・横並び・障害物越しでも線の出入りの方向が正しい。
