## 前提

## 実装項目（上から順に、1つずつでよい）

1. 明暗2つのパレット辞書を作り、110キーを両方に用意する。
2. ボタン・入力欄・メニュー・スクロールバーの共通スタイルを作る。
3. ヘッダー、タブ列、ツールバー、3列＋Splitter、ステータスバーを基準寸法で配置する。
4. アイコンを用意して組み込み、未選択時の右パネルと空のCanvasを表示する。
5. ThemeManagerでテーマ切替（Ctrl+Shift+D）を実装する。未接続のコマンドは進捗メモに残す。

## 終了条件

- [ ] 1440×860で構成・字体・色が仕様どおりに並ぶ。
- [ ] 明暗の切替で背景・文字・入力欄がその場で変わる。
- [ ] Splitterで左右パネルの幅を変えられ、最小幅を下回らない。

## 確認の作り方

色は目視で確認する。キーの数と名前が両テーマで一致することだけ機械的に確かめる。
