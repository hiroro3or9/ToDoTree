## 実装項目（上から順に、1つずつでよい）

1. 深いコピーのスナップショットでUndo/Redoを実装する。
2. Enter / Shift+Enter / F2 / Space / Delete / Ctrl+E / 矢印キーと右クリックメニューを繋ぐ。
3. 右パネルでタイトル・メモ・種別・状態・期限・見積り・タグ・固定を編集できるようにする。
4. 線へのステップ挿入とステップの分割を実装する。
5. IMEと入力欄へのイベント振分けを確認する（specs/03の「入力の優先順位」）。

## 終了条件

- [ ] カードを足してそのまま名前を入力でき、日本語変換のEnterでカードが増えない。
- [ ] 一括完了・一括移動・削除をそれぞれ1回のUndoで戻せる。
- [ ] テキスト編集中のCtrl+Z / Ctrl+C / Deleteがグラフを操作しない。
- [ ] Escでの取消や、値が変わらない操作で履歴が増えない。

## 確認の作り方

Undoの粒度（1操作＝1件）はテストで固定する。IMEは実際に日本語を打って確認する。
