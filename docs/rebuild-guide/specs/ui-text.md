# 画面の文言

画面に出る日本語はここに合わせる。勝手に言い換えない。
`{}` は実行時に差し込む値。

## ツールバー・メニュー

| 位置 | 文言 |
|---|---|
| ツールバー | `ファイル ▾` / `保存` / `＋ 続き` / `ステップ ▾` / `全体を整列` / `表示 ▾` |
| ツールチップ | `プロジェクトの作成・読み込み・保存` / `保存 (Ctrl+S)` / `選択中のステップの続きを追加 (Enter)` / `ステップの追加・接続・分割・削除` / `ブロックの中は動かさず、未所属のステップを並べ直します` / `配置方向・カード表示・最長経路・フォーカス` |
| 右端アイコン | `元に戻す (Ctrl+Z)` / `やり直す (Ctrl+Y)` / `縮小 (Ctrl+-)` / `拡大 (Ctrl++)` / `全体表示 (Ctrl+0)` |
| ファイル ▾ | `新しいプロジェクト`(Ctrl+N) / `開く`(Ctrl+O) / `保存`(Ctrl+S) / `名前を付けて保存`(Ctrl+Shift+S) |
| ステップ ▾ | `内部ステップを追加` / `続きを追加`(Enter) / `並行して追加`(Shift+Enter) / `独立したステップを追加` / `ここから繋ぐ`(Ctrl+E) / `分割` / `ブロックにまとめる`(Ctrl+G) / `ブロックを解除`(Ctrl+Shift+G) / `ブロックから外す` / `削除`(Delete) |
| 表示 ▾ | `横に流す` / `縦に流す`（切替で入れ替わる） / `カード表示` / `ミニマル` / `最長経路` / `経路を隠す` / `全体を整列` / `中を整列` / `全部開く` / `全体表示` |
| タブ列 | `今日の完了（全プロジェクト）` / `＋`（ツールチップ `新しいプロジェクトをタブで開く`） / `×`（`このプロジェクトを閉じる`） |

## ヘッダー

- 検索欄のプレースホルダ `検索 (Ctrl+F)`、読み上げ名 `ステップを検索`。
- 検索欄のツールチップ `タイトル・メモ・タグから探す (Ctrl+F)`＋改行＋`↓: 一覧へ / Enter: 選択した結果へ / Esc: 検索を解除`。
- タグ欄 `タグで絞り込む` / 解除は `タグの絞り込みをやめる` / 検索解除は `検索をやめる`。
- 文書名欄のツールチップ `プロジェクト名`。

| 部分 | 文言 |

| 受信箱 | 見出し `受信箱（仮置き）` / `未整理 {n} 件` / 説明 `名前だけ残して、あとでグラフへ配置` / ボタン `追加` `配置` / 削除 `受信箱から削除（Ctrl+Zで戻せます）` / 読み上げ名 `受信箱に追加するToDo` |

| ステップ一覧 | 見出し `ステップ一覧` / `表示 {n} 件` / 空のとき `表示できるステップがありません。検索語・タグ・「完了を隠す」を確認してください。` / チェック `完了を隠す`（ツールチップ `済んだステップをキャンバスと一覧から外す`） |

## 中央

- 見出し `ゴールへの道のり`、ボタン `全体表示`（ツールチップ `全体表示 (Ctrl+0)`）。
- 操作ヒント `Enter で次のステップ、ドラッグで移動、右端の丸から線を引いて繋げます。`
- 接続点のツールチップ `右からドラッグして、次のステップに繋げます`（左/上/下も同じ形）。
- 空のとき `カードをクリックするか、＋ 続き で追加してください`
- 階層の中にいるときは上部にパンくずと `‹ 戻る`。一覧のツールチップは
  `Enter でカードの位置へ、ダブルクリックで作業の内部へ移動します`。
- 右パネルの内部ステップ追加ボタンは `内部ステップを追加`。

| 前後 | `先行（これが終わると着手できる）` / `後続（これが終わると進める）` / 項目 `このステップへ移動` / `この繋がりを外す` |
| しおり | 見出し `作業のしおり` / `選択したカードにしおりを置く` / `しおりへ戻る` / `しおりを外す` / ラベル `再開メモ（次にすること・詰まったこと）` / ツールチップ `プロジェクトに1つ保存できます。別のカードに置くと再開メモも置き換わります。` |

## 今日完了したタスク（別ウィンドウ）

タイトル `今日完了したタスク — 全プロジェクト`、
説明 `閉じたプロジェクトも含めて、今日の作業を振り返れます。` と
`開いた・保存したプロジェクトが対象です。閉じたプロジェクトは保存済みの内容を表示します。`
見出し `{yyyy/MM/dd} ・ {n} 件完了 ・ {n} プロジェクトを確認`、ボタン `更新`、
空のとき `今日はまだ完了したタスクがありません。`、
読めないファイルがあるとき `読み込めなかったプロジェクトがあります`。
プロジェクトの状態表示は `開いています` / `閉じています` / `未保存のプロジェクト`。
