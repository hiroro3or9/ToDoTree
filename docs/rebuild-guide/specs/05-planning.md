# 05 着手判定・計画・表示

## 着手判定の順序

上から順に判定し、最初に当たったものを採用する。導出結果（Readiness）は保存しない。

1. 保存statusがDone / Cancelled → 同じ導出状態。
2. 手動ブロック（isManuallyBlocked）、または外側の祖先の条件が満たされない → Blocked。
3. status = InProgress → InProgress。
4. すべての先行がDone / Cancelled → Ready。
5. それ以外 → Blocked。

内部ステップがあるカードの状態は、子から自動で集計する（specs/08）。
合流はAND条件。取り消し（Cancelled）は後続を待たせないが、完了件数には数えない。
先行が後から未完了へ戻っても、すでに進行中/完了の後続を勝手に巻き戻さない。
ブロックを端点にした線は、その全子孫ノードへの依存として展開する。

## 進捗・最長経路

進捗は表示中の階層の直接のカードだけを集計する。取り消しは分母から外す。

- 件数率 = Done ÷ 対象数。対象0件なら0%。
- 重み率 = 完了した見積分 ÷ 全見積分。分母0なら件数率を使う。
- 見積り未指定は30分として扱う。

最長経路はトポロジカル順に「最も長い先行の累積見積 + 自分の見積」を求め、逆に辿って作る。
取り消したノードと、その線は除く。循環があるときは空にする。
表示中の階層のグラフ（ScopeGraph）で計算する。

## 次にやること

全体のReady / InProgressを点数付けし、表示中の階層に限って上位3件を出す。

`d = 期限.Date − 今日.Date`（日数）。上から順に判定し、理由の文言はこの表のとおりにする。

| 条件 | 点数 | 理由の文言 |
|---|---:|---|
| 最長経路の上にある | +50 | `最長経路の上にある` |
| 期限超過（d < 0） | +60 | `期限を {-d} 日過ぎている` |
| 期限まで0〜3日（0 ≤ d ≤ 3） | +40 | d = 0 なら `今日が期限`、それ以外は `あと {d} 日で期限` |
| 期限まで4〜7日（4 ≤ d ≤ 7） | +20 | `期限が近い` |
| 完了で解放される後続がn件（n ≥ 1） | +min(40, n×12) | `終えると {n} つが動き出す` |
| 子孫がn件（n ≥ 1） | +min(20, n×1.5) | n ≥ 4 のときだけ `この先に {n} ステップ控えている`（点数は1件から足す） |
| 進行中 | +15 | `すでに手を付けている` |
| 見積り30分以下（未指定含む） | +8 | `すぐ終わる` |

「解放される後続」は、未完了・手動ブロックなしの直接の後続のうち、自分以外の先行がすべてDone / Cancelledのもの。

点数の降順、同点は現在カルチャでタイトル順。
理由は点数の大きいものを2つまで「、」で連結する（同点は上の表の順）。
理由がなければ `いま着手できる`。

## 期限の逆算

1日4時間を既定とする。`minutesPerDay = max(30, 時間×60)`。
所要日数 = `max(1, ceil(見積 ÷ 一日分))`。

後続から逆順に、`LatestFinish = min(自分の期限, 各後続のLatestStart − 1日)`、
`LatestStart = LatestFinish − (所要日数 − 1)日`。
未完了で `LatestStart.Date < 今日` なら危険（AtRisk）としてカードに印を出す。
休日・勤務カレンダー・推論は使わない。

## 完了見込み

取り消しを除く未完了の見積り合計を残作業とする。既定ペースは240分/日。

完了日時のあるカードが2件以上あり、その見積り合計が0より大きいなら
`ペース = 完了した見積り合計 ÷ max(1, (最後のcompletedAt − 最初のcompletedAt).TotalDays)`。
日数は日付単位でなく時刻差の実数（例: 36時間なら1.5日）。同じ日に集中していれば1日として割る。
ペースは既定の0.25倍〜3倍（60〜720分/日）に収める。

`残日数 = ceil(残作業 ÷ ペース)`、`見込み = 今日の0時 + 残日数`。
残作業が0なら見込みなし。締切は未完了のGoalのうち最も早い期限。
余裕日数 = 期限.Date − 見込み.Date。負なら遅れとして色を変える。
期限の逆算とは別の計算なので混ぜない。

## 表示と検索

- 検索はタイトルとメモを対象にし、結果へ移動できる。
- タグ絞込、完了を隠す、枝の折りたたみ、祖先/子孫のフォーカス、ブロック集中を組み合わせられる。
- 共有している合流先を、一方の枝を畳んだだけで消さない。見えない線は描かない。
- 検索や非表示は**表示の都合**であって、進捗の分母や着手判定を変えない。
- しおり・完了一覧・阻害原因からの移動では、必要な階層と非表示を解除して対象を中央に出す。

## 今日完了したタスク

Doneかつ completedAt のローカル日付が今日のもの。新しい時刻順に並べる。
取り消し、完了日時なし、削除済みは含めない。

- 現在タブの一覧は表示フィルターに依存せず、5秒周期と編集のたびに更新する。日付またぎに対応する。
- 全プロジェクトの一覧は、開いている文書はメモリを優先し、閉じている既知のパスは保存ファイルを読む。
  一覧を開くだけでタブを開いたり保存したりしない。
- 読めないファイルは個別に一覧の下部へ理由を出し、他の結果を妨げない。
- パスは正規化し、大文字小文字を無視して重複を除く。5秒周期と更新ボタンの両方を備える。
