# 02 画面・描画仕様

## 全体

標準WPFウィンドウ。初期1440×860 DIP、最小900×560。DIPは96DPI基準の論理ピクセル。
FontFamily=`Yu Gothic UI, Meiryo UI, Segoe UI`、FontSize=12.5。
TextFormattingMode=Display、TextRenderingMode=ClearType、UseLayoutRounding=True。
初期はライトテーマ、カード表示、左→右。
アイコンは移行先で用意し、ApplicationIconとWindow.Iconに指定する（原案は角の丸い四角にアクセント色、中に枝分かれの木）。
タイトルバーにはアクティブ文書名と未保存状態を反映する。文言は[ui-text](ui-text.md)。

上から、ヘッダー／タブ列／ツールバー／作業領域／ステータスバー。

## 配色

色は[palette.md](palette.md)の値をそのまま使う。キー名は両テーマで同じにし、`DynamicResource`で引く。
色指定はWPFの`#AARRGGBB`。先頭2桁はアルファなので、`14...`を不透明なRGBとして解釈しない。
テーマ切替は辞書の差し替えで即時反映する。自前描画の線・ミニマップも切替通知で再描画し、
古い色をキャッシュに残さない。

Canvasのドットは26×26の繰返し、中心(1,1)、半径0.8。

## カードと線

- 標準カードの基準箱224×88。角丸12前後、淡い影、左端に種別色の帯（幅4前後）。
  上段に状態と種別、中央にタイトル、下段に見積り・期限・タグなどのメタ情報。
- ミニマル表示は24×24の丸。名前は箱の外に短く出し、選択/ホバーで全体と操作を見せる。
- 種別: 出発点Start、ステップStep、節目Milestone、ゴールGoal。帯の色は`Kind.*`。
- 状態: Readyは緑系の枠、InProgressは青紫系、Blockedは淡い通常枠、Doneは薄く取り消し線、
  Cancelledは実績を保ったまま非アクティブな見た目。
- 状態の輪郭とは別に、選択、最長経路、期限超過、危険（着手が間に合わない）、ブロック所属、
  しおりの旗を描く。同時に立つときは 選択 > 最長経路 > 期限超過 の順で色を優先する。
- 右端の丸から線を引いて接続する。ホバー/選択時だけ出る操作をカード本体のクリックと誤認しない。
- 描画順は Canvas背景 → ブロックの囲み → 線 → カード。矢印、状態色、選択、通過点を描く。
- ミニマップはノード・ブロックと現在の視野を示し、クリックで画面を移動する。

## 座標

`screen = world × zoom + pan`。ホイールはカーソル位置のworld座標を固定して1.12倍／その逆数。
zoomの範囲0.25〜2.5。全体表示の倍率上限は1.2。
新規カード・囲み・線・ヒットテスト・ミニマップを同じ座標系に揃える。
ドラッグ中はズーム・panを動かさない。

## 見た目の合わせ方

配置 → 字体 → 色 → 影 → 操作状態の順に確認する。
寸法は上の表と[ui-text](ui-text.md)の文言を基準にし、1回の作業では1つの領域だけ直す。
