# 08 カードの内部ステップ・コピーと貼り付け

## 内部ステップ

通常カードは、`parentTaskId` で他のカードの内部に入れられる。深さは任意。
**依存線とは別の情報**で、線の前後関係と混ぜない。

### 階層の移動

- 通常カードのダブルクリックで、そのカードの内部へ入る。
- 上部のパンくずで任意の祖先へ、`‹ 戻る` で1段上へ戻る。戻ったときは元の親カードを選択状態にする。
- 階層を移動したら、検索・タグ・完了非表示・フォーカス・枝の折りたたみ・選択を解除して全体表示にする。
- ステップ一覧・Canvas・進捗・自動整列は、**現在の階層の直接の子だけ**を対象にする。
- 保存・削除・コピーは内部を含む全体を対象にする（表示の範囲と扱う範囲は別）。

### 状態の集計

- 内部の着手条件に、外側のすべての祖先について「手動ブロックされていない」
  「Cancelledでない」「依存が完了している」を加える。どれか欠ければ内部はBlocked。
- 深い階層から順に集計する。直接の子が全員 Done / Cancelled なら親はDone
  （子が全員Cancelledの場合も親はDone。親をCancelledにはしない）。
  そうでなく Done か InProgress の子がいれば親は InProgress。それ以外は NotStarted。
- 完了へ変わったときだけ CompletedAt を入れ、未完了へ戻ったら null にする。
- **子を持つ親の状態を直接変更させない。** 内部を編集して自動で集計させる。
- カードには `内部 {Done}／{Total} 件完了` を出す。

### 禁止すること

- 階層をまたぐ直接の依存線とブロック。作ろうとしたら拒否する。
- 内部親が存在しない、自分自身や子孫を親にする（循環）。読込時も拒否する。
- 親を削除したら内部も全部消える。Undoで内部ごと元に戻す。

## コピーと貼り付け

選択したアイテムを Ctrl+C でコピーし、Ctrl+V で**現在の階層**へ貼り付ける。
右クリックの `ここに貼り付け` はカーソル位置へ置く。

| 対象 | 扱い |
|---|---|
| カードの状態・チェック・期限・手動ブロック | コピーした時点のまま保持する |
| 内部ステップ | 子孫まで含める |
| 選択範囲の中で閉じた辺、ブロックとポート | 含める |
| 選択範囲の外へ出る辺 | 含めない |
| 座標 | 選択範囲の中の相対位置を保つ |
| ID | すべて新規に採番し、内部親・辺・ポートの参照を新しいIDへ置き換える |
| 保存先 | アプリ専用の形式でクリップボードへ入れる（他アプリへ貼る用途は考えない） |

- 貼り付け先に既存のカードと重なるときは、貼り付けた全体を下へずらす。
- 貼り付けた後は、貼った物を全選択し、フォーカス表示を解除する。
- 貼り付け全体を**1回のUndo**で取り消せる。
- 何も選択していないCtrl+Cと、空のクリップボードのCtrl+Vは何もしない。
