# 03 基本操作と入力

## グラフ編集

- クリックでカード選択、Ctrl+クリックで追加/解除。背景Alt+ドラッグで矩形選択。Ctrl+Aは現在見えるステップ。
- 背景ドラッグでpan。カードドラッグは選択した全カードを相対位置のまま動かす。線・通過点も選択できる。
- Enterは選択カードの後続を作る。Shift+Enterは同じ先行を持つ並行作業。未選択なら独立ステップ。
  新規名は「新しいステップ」。作成直後にカード上で名前編集に入る。連続Enterで列を伸ばせる。
- F2でカード名編集。名前入力中のShift+Tabにも並行追加の経路を用意する。
- 通常カードのダブルクリックは**内部へ入る**（名前編集ではない）。パンくずと `‹ 戻る` で戻る。
- 接続は接続元の丸から相手へドラッグ、またはCtrl+Eで開始して対象を選びEnter。Escで中止。
- A→Bの線のメニューから A→新規→B へ挿入できる。ステップの分割は入出力を保ったまま2枚に割る。
  分割後は接続・所属・座標・Undoを確認する。
- Ctrl+Cで選択アイテムをコピーし、Ctrl+Vで現在の階層へ貼り付ける（specs/08）。
- Deleteで対象のカード/線/通過点を削除する。親カードの削除は内部ステップも一緒に消す。ブロック選択中のDeleteでは解除せず、Ctrl+Shift+Gを案内する。
- Spaceで選択カードを完了にする。複数選択でも1回のUndo。すでに完了したカードは巻き戻さない。
  キーリピートの押しっぱなしで二重に処理しない。
- 種別、状態、期限、見積り(分)、タグ、メモ、位置の固定は右パネルで編集する。
  Doneへ変えたらCompletedAtを入れ、完了を解除したらnullへ戻す。

## キー一覧

| キー | 操作 |
|---|---|
| Ctrl+N / Ctrl+O | 新規タブ / ファイルを開く |
| Ctrl+S / Ctrl+Shift+S | 保存 / 名前を付けて保存 |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+F | 検索へフォーカス |
| Ctrl+E | キーボードで接続を開始 |
| Ctrl+G / Ctrl+Shift+G | ブロック作成 / 解除 |
| Ctrl+L | ブロック選択中なら内部整列、それ以外は全体整列 |
| Ctrl+0 / Ctrl++ / Ctrl+- | 全体表示 / 拡大 / 縮小 |
| Ctrl+Shift+D / Ctrl+Shift+M | 配色切替 / カードとミニマルの切替 |
| Ctrl+C / Ctrl+V | 選択アイテムのコピー / 現在の階層へ貼り付け |
| Ctrl+Shift+↓ | この枝を選択 |
| Enter / Shift+Enter | 続きを追加 / 並行して追加 |
| F2 / Space / Delete | 名前編集 / 達成 / 削除 |
| 矢印 | 空間的な位置関係で選択カードを移動 |
| Esc | 接続・ドラッグ・命名など現在の操作を終了または取消 |

## 入力の優先順位

ここを外すと日本語入力が壊れるので、実装の早い段階で確認する。

- TextBox等を編集中は、文字のコピー・Undo・Deleteを優先し、グラフ操作を発火させない。
- IMEの処理キーはテキスト入力へ渡す。**変換確定のEnterで次のカードを追加しない**。
- ButtonBaseのSpace/Enterはボタンの処理へ渡す。入力確定と操作を二重に発火させない。
- 検索中はEscで解除、↓/Enterで結果の移動・確定。

## ドラッグの約束

ドラッグは「開始前のスナップショット」と「現在の候補」を持つ。
MouseUpで1操作として確定し、Escで開始位置へ戻す。
マウスキャプチャの喪失・ウィンドウの非アクティブ化・タブ切替でも、中途半端な状態や
描画の残りを残さない。ブロック命名で空白のままならタイトルを「新しいブロック」に戻し、
作成直後のEscは作成ごと取り消す。
