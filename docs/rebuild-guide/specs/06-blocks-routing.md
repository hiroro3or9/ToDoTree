# 06 ブロック・配置・線・吸着

## ブロック

- 2件以上を選択してCtrl+G。未所属同士ならトップレベル、同じ囲みの直接所属同士なら子ブロック。
- titleの既定は「新しいブロック」。作成直後に名前編集へ入る。
- 一つのノードが直接所属できるのは一つのブロックだけ。祖先への間接所属は保存しない。
- 枠は所属カードと子ブロックから算出する。左右24・下24、見出し32、見出しと内容の間12。
- 見出しをクリックでブロック選択。内部カードには破線の印を出す。カード自体を押せば通常の選択。
- 見出しのドラッグで全子孫を平行移動する。内部で閉じた線の通過点は一緒に動かし、
  外部と繋がる線の通過点はそのまま残す。
- **所属の変更はShift+ドラッグだけ**。カードのShift+ドラッグで所属変更、
  見出しのShift+ドラッグで親ブロックの変更。自分自身や子孫への移籍、循環する所属を拒否する。
  通常のドラッグでは所属を変えない。
- 解除（Ctrl+Shift+G）は囲みだけを外し、カードは消さない。
  ブロックを端点にしていた線は、実際の依存が変わらないよう個々のノードへ展開する。
- 続き/並行の追加は起点の囲みを継承する。線への挿入は両端が同じ囲みのときだけ継承。
  背景からの新規カードは未所属。
- 一部だけ非表示のブロックは見出しに「表示 n / 全 m 件」を出し、見えない移動を防ぐため移動不可にする。
  全部隠れたら枠も隠す。折りたたみとは別の状態として扱う。

## 接続と折りたたみ

node→block、block→node、block→block を張れる。実効辺は両端の全子孫の直積。
同じ端点の組の重複、展開後の自己接続や循環は拒否する。

折りたたみはノードを消さずに内部座標を保ったまま小さな見出し表示へ変える。
内部ノードへの外部線は折りたたんだ枠へ投影し、同じ見え方になる線はまとめて描く。
集中表示は囲みの中と、そこに直接つながる外部だけを表示し、解除で以前の視野へ戻す。

ポートは辺（Left/Right/Top/Bottom）と割合0〜1で表す。Autoはカスタムポートとしては無効。
辺の標準の丸からも線を作れる。追加・移動・削除するポートはIDで線と結ぶ。
移動時は最も近い辺へ投影し、上下辺ならX、左右辺ならYを0〜1に正規化する。
参照されているポートを削除したら、線は標準位置へ戻すだけで消さない。

## 配置

| 値 | Card | Minimal |
|---|---:|---:|
| ノードサイズ | 224×88 | 24×24 |
| FlowGap（流れ方向の隙間） | 66 | 90 |
| CrossGap（直交方向の隙間） | 40 | 80 |

`LayerSpacing = 流れ方向のサイズ + FlowGap`、`NodeSpacing = 直交方向のサイズ + CrossGap`。
左→右のCardは 290 / 128、上→下は 154 / 264。原点は(80, 80)、交差低減は8回まで。

- トポロジカルな層分けと交差低減で自動整列する。
- 全体整列ではブロック内のカードと固定カード（isPinned）を動かさず、未所属だけを囲みを避けて並べる。
- ブロック選択中のCtrl+Lは内部整列。外側の配置・見出し位置・zoom・panを変えない。
- カード表示とミニマルを切り替えたら、座標系・接続点・ヒットテスト・矩形選択・全体表示を一緒に更新する。

## 線の描画

直線の矢印で代用せず、曲線で描く。四辺の指定とAutoを扱う。
カード端から出る方向と到着辺への方向を守り、カードや囲みを避ける経路を計算する。
Waypointsは順序付きの通過点。通常は折れ、`isSmooth = true`なら滑らかに通す。
追加・移動・削除・全解除・滑らかさ切替をUndoで戻せる。通過点は依存関係を変えない。
色は既定または9色のプリセット。選択・最長経路・強調の状態色を優先する。

完全一致が難しい部分なので、まず「重ならない・方向が正しい・矢印が見える」を満たし、
細かな曲がり方は後から詰める。

## 吸着の計算

移動しているカード群の外接矩形を使い、左端同士 / 中心同士 / 右端同士、
上端同士 / 中心同士 / 下端同士を揃える。

| 閾値（画面座標） | 値 |
|---|---:|
| 取得距離 | 6 |
| 解除距離 | 10 |
| 直交方向の距離 | 160 |
| 保持中の直交距離 | 184 |

world距離×zoomで判定し、倍率が変わっても操作感を一定にする。
保持中の候補を優先し、細かな更新で別の候補へ飛び移らない。
候補は最短距離±0.01・直交距離±0.01で絞り、anchor順→GUID順で決める。
Altを押している間はrawDelta（吸着なし・保持なし・ガイドなし）。離せば再取得する。
移動中のカード自身、移動群を含む囲み、画面外、部分的に隠れた囲みは候補にしない。
ガイドはX/Yそれぞれ最大1本の破線。移動の途中状態は保存せず、確定または取消で消す。
