# 07 受信箱・チェック・作業ブロック・しおり

## 受信箱（仮置き）

プロジェクトに保存する、まだグラフへ置いていない項目。

- 入力欄でEnter、または「追加」で登録。`×` で削除（Undoで戻せる）。
- 「配置」ボタンかドラッグでカードに変え、受信箱から外す。
- 配置するまでは進捗にも計画（次にやること）にも含めない。
- 左パネルの見出しに「未整理 n 件」を出す。

## チェックリスト

カードの中の独立した項目。追加・名前編集・チェック・削除ができ、カードには `n/m` を出す。
**全部チェックしてもカードは自動で完了しない。** 完了は手動で行う旨を画面に明記する。

## 作業ブロック（手動ブロック）

`isManuallyBlocked` は保存statusと独立した印。理由（blockReason）は任意。

- ブロックを解除すると、以前のstatusがそのまま現れる。
- Done / Cancelledにすると印はfalseになり、理由の文字列は残す。
- 右パネルの「この作業・ゴールが止まっている理由」に、上流の手動ブロックと未完了の前提を並べる。
  Done / Cancelledより先へは原因を探しに行かない。
- 原因をクリックしたら、フィルターと階層を解除してそのカードへ移動する。
- すべての編集はUndo・保存・復旧に対応する。

## 作業のしおり

プロジェクトにつき1つ、nodeId + note（再開メモ）を持つ。

- 選択カードに設置すると、そのカードに旗の印が出る。設置・置換・メモ編集・解除はUndoで戻せる。
- 置き換えるときは古いメモも一緒に置き換える。
- カードが完了しても、しおりは残る。対象カードを削除したらしおりも外れ、Undoでメモごと戻る。
- 「しおりへ戻る」は、検索・タグ・完了非表示・フォーカス・枝とブロックの折りたたみを解除し、
  必要な階層へ移動して対象を中央に出す。
- 保存済みの文書を起動時に復元するときはしおりを優先する。
  その後のタブ切替では勝手にしおりへ飛ばない。
