# ToDoTree 作成ガイド — 最初に読む

作業をDAG（分岐と合流のある有向非巡回グラフ）で管理するWindowsデスクトップアプリを、
別環境でAIと一緒に段階的に作るための資料です。想定は **Windows + .NET 10 SDK + WPF**、外部NuGet依存なし。

このガイドはテキストだけで構成しています。既存のソースコード・スクリーンショット・
アイコン画像は含みません。アイコンは作る側で用意してください。

## 使い方

1. このフォルダーを開発先へ置く。
2. AIに [共通指示](AI_INSTRUCTIONS.md) と [段階01](phases/01.md) を渡す。
3. 指定された資料だけを読ませ、段階01の終了条件を確認する。
4. 作業の終わりに [進捗メモ](PROGRESS.md) を更新させる。
5. 次の会話では、共通指示・進捗メモ・次の段階だけを渡す。01〜14の順に進む。
6. 最後に [受入確認](ACCEPTANCE.md) を通す。

**資料全体を毎回読ませないことが、トークン節約の要点です。**
1段階が長ければ、その段階の実装項目を1つずつ実施してください。

### 最初の依頼文（コピー用）

```text
添付のToDoTree作成ガイドを使い、Windows / .NET 10 / WPFでアプリを新規作成してください。
AI_INSTRUCTIONS.mdとphases/01.mdを読み、段階01だけ実装してください。
必要な資料は段階01が指定した範囲だけ読んでください。
文言・寸法・色・データ形式を独自に変更しないでください。
完了後は確認結果と次の段階をPROGRESS.mdに記録し、短く報告してください。
```

### 続きの依頼文

```text
AI_INSTRUCTIONS.mdとPROGRESS.md、phases/NN.mdを読み、段階NNだけ進めてください。
前の段階の実装を使い、必要な資料だけ確認してください。
未解決の項目を隠さず、終了条件を確認してからPROGRESS.mdを更新してください。
```

ファイルを読めないAIなら、共通指示・その段階・指定された資料の該当節を貼り付けてください。

## 前提と限界

- 数値・文言・キー操作は実際に動いていたアプリの値です。そのまま使えば近い見た目になります。
- ただし**画像がないので、細部の一致は目視の調整**になります。フォント・DPI・ウィンドウ寸法で見え方は変わります。
- 曲線の経路と吸着の細かな挙動は、文章で書ける範囲までしか指定していません。
  「重ならない・方向が正しい・操作していて違和感がない」を基準に調整してください。
- 保存形式は他環境のファイルと互換がありません。`schemaVersion` は 1 から始めます。
- [段階一覧](IMPLEMENTATION_PLAN.md)の末尾に、この版で**作らない機能**を挙げています。
  後から足すときは、フィールドを増やして版を上げてください。
